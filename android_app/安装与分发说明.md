# 阿卡莉 · 安卓 APK（WebView 壳）

不上架、不绑定域名、不需要 HTTPS。APK 里内置一个 WebView，直接加载云服务器上的
`http://<公网IP>:<端口>/` 页面，复用现有 `用户端特用/web/` 前端与 `web_app.py` 后端，
**前后端一行都不用改**。

---

## 一、原理

```
安卓 APK（WebView 壳）
        │  http://<公网IP>:8000/   （明文，已放行）
        ▼
云服务器  web_app.py（HOST=0.0.0.0, PORT=8000）
```

- 明文 `http://` 与页面内的相对路径 `fetch('/api/...')` 全部照常工作；
- 登录态存在 WebView 的 `localStorage`，与浏览器网页行为一致；
- 无域名、无证书、无 CA、不上应用商店。

## 二、目录结构

```
android_app/
├── settings.gradle
├── build.gradle
├── gradle.properties
├── gradle/wrapper/gradle-wrapper.properties
└── app/
    ├── build.gradle
    ├── proguard-rules.pro
    └── src/main/
        ├── AndroidManifest.xml
        ├── java/com/example/akali/MainActivity.kt
        └── res/
            ├── drawable/ic_launcher.xml
            ├── layout/activity_main.xml
            ├── values/strings.xml
            ├── values/themes.xml
            ├── values/colors.xml
            └── xml/network_security_config.xml
```

> `gradle/wrapper/gradle-wrapper.jar` 是二进制文件，未随仓库提供。
> 用 Android Studio 打开时会自动补全；或在 `android_app/` 下执行 `gradle wrapper` 生成。

## 三、打包步骤

1. 安装 **Android Studio**（自带 JDK 17 与 Android SDK）。
2. `File → Open`，选择本 `android_app/` 目录，等待 Gradle Sync。
3. 打开 `app/src/main/res/values/strings.xml`，把 `server_url` 改成你的真实地址：
   ```xml
   <string name="server_url">http://43.142.42.138:8000/</string>
   ```
   - 必须 `http://` 开头；
   - 端口与后端监听端口一致（默认 `8000`）；走 nginx 反代则用 `http://IP:80/`。
4. `Build → Generate Signed Bundle / APK → APK`：
   - 首次会让你 **Create new keystore**（自建即可，与应用商店无关，随便填）；
   - 选择 `release`，完成即可在 `app/release/` 得到 `app-release.apk`。
   - 图省事也可以直接 `Build → Build Bundle(s) / APK(s) → Build APK(s)` 出 debug 包。
5. 把 `app-release.apk` 传到手机，开启「允许安装未知来源应用」后安装，桌面即出现「阿卡莉」图标。

## 四、服务器侧检查（三件事）

1. **监听地址**：`web_app.py` 在云端模式默认 `HOST=0.0.0.0`、`PORT=8000`。
   如自定义，确保 `.env` 或启动命令里 `HOST=0.0.0.0`。
   ```bash
   HOST=0.0.0.0 PORT=8000 python 用户端特用/web_app.py
   ```
   或 Docker：
   ```bash
   docker compose up -d --force-recreate akali
   ```
2. **安全组 / 防火墙**：云厂商控制台放行 **TCP 8000 入站**（走 nginx 则放行 80）。
3. **邀请口令**：`.env` 的 `AKALI_INVITE_CODE` 决定客户端登录口令（当前为 `我是小猪`）。
   口令支持中文（`users.safe_eq` 已按 UTF-8 bytes 比较）。

---

## 五、验证

- 手机浏览器先访问 `http://<公网IP>:8000/`，能打开登录页并正常对话 → APK 必然可用；
- 装好 APK 后，桌面点「阿卡莉」→ 直接进 WebView 页面；
- 站内点「退出」为关闭网页（不触发后端清记忆）；返回键优先回退网页历史。

---

## 六、可选调整

- **替换图标**：编辑 `app/src/main/res/drawable/ic_launcher.xml`（矢量），或放 PNG 到 `mipmap-*` 并把 Manifest 的 `android:icon` 改过去。
- **改应用名**：`strings.xml` 的 `app_name`。
- **横屏**：删掉 Manifest 里 `<activity>` 的 `android:screenOrientation="portrait"`。
- **收紧明文放行**：`network_security_config.xml` 改用 `domain-config` 只放行你的 IP。
