# 阿卡莉浏览器插件（PC · Chrome / Edge）

**插件本体就是用户端界面**——不是跳转壳，点图标即开完整的阿卡莉窗口（聊天 / 攻略库 / 计算工具 / 遭遇战全部可用）。

---

## 一、装到浏览器（30 秒）

1. 打开 Chrome 或 Edge，地址栏输入：
   - Chrome：`chrome://extensions`
   - Edge：`edge://extensions`
2. 右上角打开 **「开发者模式」**
   > ⚠️ **别被名字吓到**：这是**浏览器自带的开关**，作用只是"允许加载未经应用商店上架的扩展"。
   > 它与本项目的 `开发者入口/`（FX数据管理工具，用于更新底层数据、由开发者在服务器或本地运行）
   > **完全是两回事**。本插件只包含用户端界面，不含任何数据管理功能。
3. 点 **「加载已解压的扩展程序」**
4. 选择本文件夹（`浏览器扩展/`）
5. 工具栏出现阿卡莉图标 → 完成

> 若工具栏没显示：点浏览器右上角拼图图标 → 把「拂晓小秘书 · 阿卡莉」固定到工具栏。

## 二、填服务器地址（首次）

点扩展图标 → 弹出「连接设置」：

| 场景 | 填什么 |
|---|---|
| **本机自用** | `http://127.0.0.1:8000`（需先双击 `启动拂晓服务.bat`） |
| **云端服务器** | `http://你的公网IP`（如 `http://1.2.3.4`） |
| 口令（可选） | 服务器 `.env` 里的 `AKALI_INVITE_CODE`；本地自用留空 |

点「测试连接」显示 **连接成功** 即可 → 点「保存并打开阿卡莉」。

之后每次只需点扩展图标（或按 **Alt+Shift+A**）。

## 三、三种打开方式

| 方式 | 操作 |
|---|---|
| 工具栏图标 | 点一下 → 独立窗口打开阿卡莉 |
| 快捷键 | `Alt+Shift+A` |
| **划词查询** ⭐ | 任意网页**选中文字** → 右键 → **「用阿卡莉查询：“…”」** → 直接拿这句话去问阿卡莉 |

划词查询走用户端的 `?q=` 参数（见 `接口契约.md`），选中"南达科他"就能直接查角色。

## 四、改配置 / 换服务器

- 点图标前先右键扩展图标 → **「选项」**，或到 `chrome://extensions` 里点「扩展选项」
- 也可随时重新填地址与口令

## 五、插件里有什么 / 没有什么（职责边界）

| 插件包含（纯用户端） | 插件不含（开发者侧，由你在服务器/本地运行） |
|---|---|
| 聊天界面、攻略库面板、计算工具、遭遇战表单 | `开发者入口/`（FX数据管理工具）：**更新底层数据** |
| 只向服务器发请求：`/api/*` 与图片素材 | 底层数据 / 知识库文件的读写与生成 |
| 服务器地址与口令（存在你本机） | 后端服务本体（`用户端特用/web_app.py`） |

> 分工：**你**在云服务器或本地跑起后端（含知识库、底层数据）；**用户**的插件只是连上来的客户端，
> 拿不到源码、拿不到知识库文件、也碰不到底层数据。

## 六、原理（为什么不用 iframe）

| 关键点 | 说明 |
|---|---|
| **不用 iframe** | 扩展页（`chrome-extension://`）属安全上下文，加载 `http://` 的 iframe 会被浏览器按**混合内容**拦截。所以插件直接跑用户端页面本体，只把请求指向你的服务器。 |
| **跨域入口** | 用户端原生支持 `window.ARKLY_API_BASE`（请求）与 `window.ASSET_BASE`（图片素材），由 `bridge.js` 注入。 |
| **无需服务端配 CORS** | 扩展声明了 `host_permissions`，扩展页发起的请求不受 CORS 限制。 |
| **关闭自毁** | 网页版有「服务端重启→旧页面自动失效」逻辑；插件窗口是常驻应用窗口，已通过 `AKALI_NO_SELFDESTRUCT` 关闭。 |
| **界面永不脱节** | 插件页面由 `构建扩展.py` 从 `用户端特用/web/index.html` 生成，**网页改了重跑脚本即同步**。 |

## 七、改了用户端网页后，如何同步到插件

```bash
cd 浏览器扩展
python 构建扩展.py
```

脚本会重新生成 `app.html` / `app.js`（把内联脚本外置，MV3 禁止内联脚本）并刷新图标。
之后在 `chrome://extensions` 里点一下该扩展的**刷新**按钮即可。

## 八、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 点图标弹出「连接设置」 | 还没填服务器地址 → 填完保存 |
| 显示「服务器ojbk中」 | 连不上后端：地址错 / 服务没启动 / 云端防火墙没开 80 端口 |
| 图片、背景不显示 | 服务器地址填错，或后端 `/kb/` 路由异常（正常时无需处理） |
| 提示口令不对 | 口令与服务器 `.env` 的 `AKALI_INVITE_CODE` 不一致 |
| 想彻底卸载 | `chrome://extensions` → 移除；配置随扩展一起消失 |

## 九、权限说明（自用可放心）

| 权限 | 用途 |
|---|---|
| `storage` | 保存服务器地址与口令（仅在你本机） |
| `contextMenus` | 右键「用阿卡莉查询」菜单 |
| `host_permissions: http(s)://*/*` | 允许访问你填的任意服务器地址（地址由你填，插件自身不发送任何数据到第三方） |

> 若将来要上架 Chrome 应用商店，宽泛的 `host_permissions` 会触发审核问询，建议改为
> `optional_host_permissions` 在运行时申请。
